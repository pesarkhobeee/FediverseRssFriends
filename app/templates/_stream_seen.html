{# Per-viewer "seen" tracking for the stream view. Purely client-side: an IntersectionObserver adds each row's item id to a Set in localStorage as the row is first scrolled into view. On subsequent loads (including HTMX Load-more swaps) already-seen rows get hidden via CSS. A "Show seen" toggle in the header flips visibility. Storage key is scoped per-owner so viewing /u/a and /u/b keeps separate sets. Bounded at 5000 ids to keep localStorage small. No cross-device sync — that would be Option 3 (server-side). #}
